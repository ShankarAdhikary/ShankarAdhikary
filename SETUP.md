# Install this GitHub profile README

1. Create a **public** repository named exactly `ShankarAdhikary` (same spelling as your GitHub username), if it does not already exist.
2. Upload `README.md`, the `assets/` folder, and the `.github/workflows/snake.yml` file, preserving the folder structure.
3. In the repository, open **Settings → Actions → General → Workflow permissions** and allow read and write permissions.
4. Open **Actions → Generate contribution snake → Run workflow** once. The workflow also runs daily.
5. Wait for the `output` branch to be created. The contribution animation will then appear in the README.

Notes:
- The README uses hosted SVG widgets for typing, statistics, streaks and technology icons.
- GitHub may cache images, so updates can take a little time to appear.
- Replace the LinkedIn link with your actual profile URL.
- Replace the featured project descriptions or add repository links when those repositories are public.
- GitHub README content cannot run JavaScript/WebGL; the motion here uses SVG/GIF-compatible embeds and a scheduled generated SVG.
